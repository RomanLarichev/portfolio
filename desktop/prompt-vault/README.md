# Промптека

**Промптека** — настольное приложение для Windows, которое помогает хранить, редактировать, систематизировать и выполнять промпты для искусственного интеллекта. В одном рабочем пространстве объединены библиотека шаблонов, вложения, переменные, история версий и инструменты подготовки задач для ИИ.

> Проект находится в активной разработке. Этот репозиторий может использоваться как демонстрация приложения и его архитектуры; наличие исходного кода или установщика определяется содержимым конкретного релиза.

## Возможности

### Библиотека промптов

- Создание, редактирование, поиск, избранное и архив.
- Коллекции и вложенные разделы для организации библиотеки.
- Компактный и подробный режимы списка.
- Светлая и тёмная темы, фокус-режим для работы без лишних панелей.

### Редактор и Master Prompt

- Обычные промпты и **Master Prompt** с редактируемыми секциями.
- Режимы редактирования и предварительного просмотра секций, включая Split/Preview.
- Параметризованные шаблоны с полями разных типов, обязательными значениями и готовым предпросмотром.
- Единое сохранение через кнопку «Сохранить» и `Ctrl+S`.

### Вложения и подготовка задач

- Работа с файлами и папками, ролями и связями вложений.
- Именуемые слоты файлов и сохранённые профили запуска.
- Подготовка ZIP-пакетов задач для ИИ с манифестом и описанием состава.
- Импорт и экспорт пакетов; экспорт в PDF.

### Выполнение и история

- Профили подключения к OpenAI, Claude, Gemini и Grok; тестовый Mock-режим.
- История выполнений и сохранение результатов.
- Предварительное заполнение переменных и назначений вложений для запуска.

> Для обращения к внешним API требуются собственные ключи и доступ к соответствующим сервисам; оплата провайдеров, если она необходима, осуществляется отдельно.

### Версионирование и восстановление

- Единая история версий обычных промптов и Master Prompt.
- Снимки состава вложений, ролей и связей с историческими копиями файлов.
- Сравнение двух выбранных версий: текста, секций, вложений и структуры.
- **Выборочное восстановление** текста/секций, состава файлов и ролей/метаданных.
- Контрольная точка перед восстановлением; одна операция восстановления создаёт одну новую пользовательскую версию.
- Резервное копирование и восстановление библиотеки с историческими вложениями.

- Electron
- React + TypeScript
- Vite
- SQLite, `better-sqlite3`, Drizzle ORM
- Node.js

## Интерфейс

Основные рабочие вкладки: **Переменные**, **Редактор**, **Вложения**, **Выполнение**, **Версии**. Доступность отдельных вкладок зависит от типа промпта и его содержимого.

Для портфолио рекомендуется добавить реальные скриншоты программы: библиотека, Master Prompt в тёмной теме, вкладка «Выполнение», сравнение версий и выборочное восстановление. Не используйте демонстрационные макеты вместо скриншотов работающего приложения.

## Установка и использование

Установщик Windows предоставляется через опубликованный релиз или по условиям распространения продукта. Для готовой сборки не требуется запускать исходный код проекта.

При наличии исходников проекта шаги локальной разработки зависят от текущей конфигурации `package.json`. Перед сборкой рекомендуется ознакомиться с документацией конкретного релиза и сделать резервную копию пользовательских данных.
