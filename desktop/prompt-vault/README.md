# 🚀 PromptVault Desktop

Локальное десктопное приложение для управления, версионирования и генерации AI-промптов. Разработано с упором на производительность, безопасность данных (локальное хранение) и удобство UX.

> 💡 **Примечание:** Этот проект демонстрирует навыки full-stack разработки десктопных приложений, работы с локальными БД, архитектуры Clean Architecture и написания автотестов, что напрямую пересекается с моей основной специализацией QA Automation.

## 🛠️ Технологический стек

- **Frontend:** React 19, TypeScript, Ant Design, Zustand (state management)
- **Backend (Desktop):** Electron, Node.js
- **Database:** SQLite (better-sqlite3) + Drizzle ORM (type-safe queries & migrations)
- **Build & Tooling:** Vite, `vite-plugin-electron`, `electron-builder`, Oxlint
- **Testing:** Vitest (Unit & Integration tests)

## ✨ Ключевые возможности

1. **Полноценный CRUD** с фильтрацией, поиском (fuzzy search) и сортировкой.
2. **Версионирование контента:** автоматическое сохранение истории изменений с возможностью просмотра Diff и отката к предыдущим версиям.
3. **Master Prompt Mode:** структурированное редактирование промптов по секциям (Role, Objective, Context и т.д.) с live Markdown-превью.
4. **Экосистема:** Экспорт/Импорт библиотеки в Markdown (совместимо с Obsidian/Notion) и JSON.
5. **Продуктивность:** Глобальная палитра команд (`Ctrl+K`), хоткеи (`Ctrl+S`, `Ctrl+Shift+C`), автосохранение и история недавних открытий.
6. **UI/UX:** Поддержка светлой и темной темы, адаптивные skeleton-загрузчики.

## 🏗️ Архитектура проекта

Проект следует принципам разделения ответственности:
- `src/domain/` – бизнес-модели и чистая логика (парсинг переменных, diff-алгоритмы).
- `src/application/` – сервисы, координирующие работу репозиториев.
- `src/infrastructure/` – работа с БД (Drizzle ORM), IPC-мосты Electron.
- `src/features/` – React-компоненты, сгруппированные по функциональным областям.

## 🚀 Как запустить

### Предварительные требования
- Node.js >= 20.x
- npm или pnpm

### Установка и запуск в режиме разработки
```bash
# 1. Клонировать репозиторий (если еще не)
git clone <ваш-url-репозитория>
cd portfolio/desktop/prompt-vault

# 2. Установить зависимости
npm install

# 3. Запустить приложение (откроется окно Electron с hot-reload)
npm run dev

# 4. (Опционально) Наполнить БД демо-данными
npm run seed
